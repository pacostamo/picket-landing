# Picket — Landing Page

Landing estática lista para GitHub Pages. No requiere React, Node, Base44 ni backend.

## Publicar
1. Crea un repositorio en GitHub.
2. Sube `index.html`, `styles.css` y `script.js` a la raíz.
3. Settings → Pages → Deploy from a branch → `main` / root.

## Formulario
El formulario usa `mailto:soporte@picket.app` para preparar un correo. Puede conectarse luego a un backend o servicio de formularios si se desea recepción automática.
